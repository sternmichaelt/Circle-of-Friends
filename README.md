# Circle of Friends

A web app to track your friends by closeness and view them as relationship circles. Your data saves in this browser on your device (no account required yet).

## How to open the app

1. Open Terminal and go to this project folder.
2. Install dependencies (first time only):

```bash
npm install
```

3. Start the app:

```bash
npm run dev
```

4. In your browser, open [http://localhost:3000](http://localhost:3000).

## What you can do

- Add people and place them in a tier (Inner Circle, Close Friends, Friends, Acquaintances)
- Switch between Concentric Circles and Stacked View
- Open a person to edit email, phone, company, birthday, and notes
- View simple stats for each tier
- Refresh or close the tab — your list stays on this device

## Later

Cloud sync with Supabase can replace the local save layer without rebuilding the screens.
